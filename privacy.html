プライバシーポリシー（youtube-analyse）

最終更新日：2026年10月6日

youtube-analyse（以下「本アプリ」）は、運営者が自ら運営する YouTube チャンネル（「ご先祖の家計簿」「生き物の理不尽図鑑」「実はこうだった研究所」）の動画制作を改善するため、運営者本人のみが利用する内部ツールです。第三者に向けて提供するサービスではありません。

1. 取得する情報

本アプリは、運営者が Google の同意画面で許可した範囲で、YouTube Analytics API および YouTube Data API から、運営者自身のチャンネルについて次の情報を読み取ります。

  • チャンネル ID・チャンネル名
  • 動画ごとの集計値（再生回数、視聴時間、平均視聴率、高評価数、コメント数、共有数、登録者の増減など）

本アプリが利用する権限は読み取り専用（yt-analytics.readonly、youtube.readonly）です。動画の投稿・編集・削除、コメントの投稿などは行いません。視聴者個人を特定する情報は取得しません。

2. 利用目的

取得した情報は、運営者のチャンネルの動画企画・台本の改善（どの題材や構成がよく見られたかの分析）にのみ利用します。広告配信、販売、プロファイリングには利用しません。

3. 保存と管理

認証情報（アクセストークン・リフレッシュトークン）と集計値は、運営者が管理するコンピュータ内にのみ保存し、アクセス権限を運営者に限定しています。外部のサーバーへ送信・公開することはありません。

4. 第三者提供

取得した情報を第三者に販売・提供することはありません。ただし、法令に基づく場合を除きます。

5. Google API サービスの利用について

本アプリによる Google API から受け取った情報の利用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。YouTube API サービスの利用にあたっては、YouTube 利用規約および Google プライバシーポリシーが適用されます。

6. アクセス権の取り消し

本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消した場合、本アプリは以降の情報取得を行いません。保存済みのデータは、運営者への連絡により削除します。

Privacy Policy (youtube-analyse)

youtube-analyse is an internal, owner-only tool. With the owner's consent it reads, in read-only mode (yt-analytics.readonly, youtube.readonly), the owner's own YouTube channels' IDs, names and per-video aggregate metrics, solely to improve the owner's video planning. It never posts, edits or deletes content, collects no viewer personal data, stores tokens and data only on the owner's computer, and never sells or shares data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
